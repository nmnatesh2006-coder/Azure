☁️ Microsoft Azure Cloud Computing Project

📌 Project Overview

This project demonstrates the implementation and deployment of different Microsoft Azure cloud computing services. The project explores Azure Virtual Machines, Azure CLI/Cloud Shell, Azure Container Instances, and Azure Blob Storage for hosting web content.

The main objective is to understand how cloud infrastructure and services can be created, configured, accessed, and deployed using Microsoft Azure.

---

🎯 Objectives

- Understand the fundamentals of Microsoft Azure.
- Create and manage Azure cloud resources.
- Access Azure resources using Azure CLI and Cloud Shell.
- Connect to an Azure Virtual Machine using SSH.
- Deploy applications using Azure Container Instances.
- Store and host web files using Azure Blob Storage.
- Understand basic cloud deployment and hosting workflows.

---

☁️ Azure Services Implemented

1. Azure Virtual Machine

An Azure Virtual Machine was created and accessed through the Azure environment. SSH was used to establish a connection with the virtual machine and interact with the cloud-based system.

2. Azure CLI / Cloud Shell

Azure Cloud Shell was used to execute cloud management commands and interact with Azure resources through the command line.

3. Azure Container Instances

An application/container was deployed using Azure Container Instances (ACI). The deployed container was accessed through its public endpoint, demonstrating container-based application deployment in Azure.

4. Azure Blob Storage

Azure Blob Storage was used to store web-related files and make them accessible through Azure storage.

A static website was hosted using Azure Blob Storage, demonstrating how cloud storage can be used for web hosting.

💻 Azure Virtual Machine

The Azure Virtual Machine provides a cloud-based computing environment. The virtual machine was created through Azure and accessed using SSH.

Process

1. Create a Virtual Machine in Azure.
2. Configure the required VM settings.
3. Obtain the required connection details.
4. Connect to the VM using SSH.
5. Access and manage the cloud-based machine.

---

🖥️ Azure Cloud Shell

Azure Cloud Shell provides a browser-based command-line environment for managing Azure resources.

Azure CLI commands can be executed directly through Cloud Shell without requiring a local Azure CLI installation.

Key Uses

- Manage Azure resources.
- Create and configure services.
- Execute Azure CLI commands.
- Monitor and interact with cloud resources.

---

📦 Azure Container Instances

Azure Container Instances provides a simple way to run containers in Microsoft Azure without managing virtual machines.

The container application was deployed using Azure Container Instances and accessed through its public endpoint.

Process

1. Prepare the application/container.
2. Create an Azure Container Instance.
3. Configure the container settings.
4. Deploy the container.
5. Access the application using the public endpoint.

---

🗄️ Azure Blob Storage

Azure Blob Storage is used to store files and web content in the cloud.

In this project, web files were uploaded to Blob Storage and used for static website hosting.

Process

1. Create an Azure Storage Account.
2. Create the required storage container.
3. Upload the web files.
4. Configure static website hosting.
5. Access the hosted website.

---

📊 Results

The project successfully demonstrates the use of multiple Microsoft Azure cloud services. A Virtual Machine was created and accessed using SSH, Azure CLI commands were executed through Cloud Shell, an application was deployed using Azure Container Instances, and web content was hosted using Azure Blob Storage.
